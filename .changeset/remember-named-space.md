`mnemon_remember` now writes into the Memory Space it names, or nowhere, and a write no longer switches a space back on by itself (#387). The delegated writer used to treat the named space as a preference and could put the memory into another space whose description matched it better, switching that space back on if someone had switched it off. The Host now checks a named space before the writer starts and refuses an unknown one, one whose Provider is off or takes no writes, and one that is switched off: a model switches such a space on first with `mnemon_memory_body_update`, while a space the user picks on the Memory Spaces page still comes back on with the write. A guard on the writer refuses a write or a link into any other space; without a named space it refuses a space that was switched off when the run started, and saving a memory never merges spaces. Save to memory follows the same rules. The result's `memoryBodyIds` now come from the Source receipts rather than the writer's own report, and `activatedMemoryBodyIds` lists a space the write switched on. A delegated child is refused memory tools once its run has ended, so a finished writer or idle review that DSH 0.2.1 resumes after another Agent's message cannot write again.
