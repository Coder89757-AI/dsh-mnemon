The Memory System shows what **Sync now**, **Merge here only**, a ZIP import or an applied **Memory reconciliation** plan on the Plugins page brought in, without pressing Refresh: its open page reads the data again as soon as the action finishes, also while the Memory System is hidden. A sync, a ZIP import and a plan also do this when they report a failure after writing part of their work. Checking the remote or a ZIP writes nothing and reloads nothing. An automatic sync runs in the background and still needs Refresh.
