A new Source, `dsh-mnemon-source-skills`, adds a **Skills** tab to the Memory System and ships with the Starter. It lists the `SKILL.md` files DSH loads from `.dsh/skills`, `.agents/skills`, `~/.dsh/skills` and `~/.agents/skills`, switches a skill out of the model's reach or the `/` menu with DSH's own frontmatter keys, edits it under a hash fence, keeps every change as a version that can be compared and restored, and moves a deleted skill to a trash folder. Self-evolution, off until it is turned on, captures each conversation's trajectory as turns end; once a window reaches the post-turn review score and the conversation sits idle, a task Agent reviews it for strong signals — corrections, "from now on", tool failures, a reusable procedure, a skill extended at runtime — and suggests a new skill or an update, citing the steps it rests on. The annotated trajectories are kept as evidence, proposed eval cases join each skill's eval set, and a suggestion is evolved by a draft that is backtested against the current version (or against no skill) before it is adopted, edited or redrafted with guidance. Backtests are simulations: an executor follows the skill without tools and a judge grades the checks. The Source never joins a model View. The post-turn review constant is renamed `POST_TURN_REVIEW_POLICY`; its values are unchanged.

新增 Source `dsh-mnemon-source-skills`，在记忆系统中加入“技能管理”标签页，并随 Starter 安装。它列出 DSH 从 `.dsh/skills`、`.agents/skills`、`~/.dsh/skills` 与 `~/.agents/skills` 加载的 `SKILL.md`，用 DSH 自己的 frontmatter 键把技能移出模型可加载范围或 `/` 菜单，在文件哈希栅栏下编辑，把每次修改留作可对比、可恢复的版本，删除时移入回收目录。自进化默认关闭；开启后，每轮对话结束时采集轨迹，窗口达到回合复盘分且对话空闲后，由任务 Agent 按强信号（多次纠正、“以后都这样做”、工具失败、可复用流程、技能在运行时被扩展等）复盘，提出新建或更新技能的建议，并标注所依据的步骤。带标注的轨迹作为证据保存，复盘提出的评测用例并入各技能的评测集；进化时先生成草案，与当前版本（或不加载技能）对比回测，再采纳、修改或按意见重写。回测是模拟运行：执行者按技能写出步骤与答案而不调用工具，评审只按检查项打分。该 Source 不进入模型 View。回合复盘常量更名为 `POST_TURN_REVIEW_POLICY`，取值不变。
