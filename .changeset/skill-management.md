A new Source, `dsh-mnemon-source-skills`, adds a **Skills** page to the Memory System — Skills, Evolution, Evals and Market — and ships with the Starter. It lists the `SKILL.md` files DSH loads from `.dsh/skills`, `.agents/skills`, `~/.dsh/skills` and `~/.agents/skills`, switches a skill out of the model's reach or the `/` menu with DSH's own frontmatter keys, edits it under a hash fence, keeps every change as a version that can be compared and restored, and moves a deleted skill to a trash folder. Each row has a switch for the whole skill and a Use button that returns to the conversation with `/name` in its input. A Market lists skills from registries — one JSON file each, the official one shipped with the package and refreshed from the repository, others added by URL or path — and installs, previews and updates them from their GitHub folder, URL or local folder. Self-evolution, off until it is turned on, captures each conversation's trajectory as turns end; once a window reaches the post-turn review score and the conversation sits idle, a task Agent reviews it for strong signals — corrections, "from now on", tool failures, a reusable procedure, a skill extended at runtime — and suggests a new skill or an update, citing the steps it rests on. The annotated trajectories are kept as evidence, proposed eval cases join each skill's eval set, and a suggestion is evolved by a draft that is backtested against the current version (or against no skill) before it is adopted, edited or redrafted with guidance. Backtests are simulations: an executor follows the skill without tools and a judge grades the checks. Evals lists every skill's cases and backtests in one place; a skill links to its own. Its settings — self-evolution, automatic backtests of drafts, the review parameters, conversation hints and a sidebar entry — sit on its component page under Plugins and apply live. With hints on, a line under each turn names the skills it used and how its review went, and opens them on the page; with the sidebar entry on, the page has its own place in the sidebar instead of a tab in the Memory System. The Source never joins a model View. A Memory System page may now call `onReturnToConversation()` to go back to the conversation. The post-turn review constant is renamed `POST_TURN_REVIEW_POLICY`; its values are unchanged.

新增 Source `dsh-mnemon-source-skills`，在记忆系统中加入“技能管理”页（技能、进化、评测、市场），并随 Starter 安装。它列出 DSH 从 `.dsh/skills`、`.agents/skills`、`~/.dsh/skills` 与 `~/.agents/skills` 加载的 `SKILL.md`，用 DSH 自己的 frontmatter 键把技能移出模型可加载范围或 `/` 菜单，在文件哈希栅栏下编辑，把每次修改留作可对比、可恢复的版本，删除时移入回收目录。每行有整个技能的开关，以及“使用”按钮：回到会话并把 `/技能名` 放进输入框。“市场”列出各注册表中的技能——每个注册表是一份 JSON，官方注册表随包提供并从仓库刷新，其他注册表可按网址或路径添加——并从其 GitHub 目录、网址或本地文件夹预览、安装与更新。自进化默认关闭；开启后，每轮对话结束时采集轨迹，窗口达到回合复盘分且对话空闲后，由任务 Agent 按强信号（多次纠正、“以后都这样做”、工具失败、可复用流程、技能在运行时被扩展等）复盘，提出新建或更新技能的建议，并标注所依据的步骤。带标注的轨迹作为证据保存，复盘提出的评测用例并入各技能的评测集；进化时先生成草案，与当前版本（或不加载技能）对比回测，再采纳、修改或按意见重写。回测是模拟运行：执行者按技能写出步骤与答案而不调用工具，评审只按检查项打分。“评测”集中列出各技能的用例与回测，技能详情可直达对应评测。设置——自进化、草案自动回测、复盘参数、对话提示与侧边栏入口——放在“插件”中该组件的页面上，修改即时生效。开启对话提示后，每回合下方会列出用到的技能与复盘状态，点击即可在页面中打开；开启侧边栏入口后，技能管理在侧边栏中独立出现，不再作为记忆系统的标签页。该 Source 不进入模型 View。记忆系统页面新增可选的 `onReturnToConversation()`，用于回到会话。回合复盘常量更名为 `POST_TURN_REVIEW_POLICY`，取值不变。
