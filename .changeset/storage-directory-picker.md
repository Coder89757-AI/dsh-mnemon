Add an optional native directory chooser beside the existing custom storage path. A picked path stays a draft until Apply; existing files, storage scopes and ZIP import behavior are unchanged. Hosts without a native chooser keep manual entry.

在自定义存储路径旁增加可选的原生目录选择器。选择结果在点击应用前仍是草稿，不改动已有文件、存储范围和 ZIP 导入行为。不提供原生选择器的宿主继续使用手动输入。
